# 战争模拟器 · Web War Simulator

一个基于 **兰彻斯特方程（Lanchester's Laws）** 的近现代战争模拟器，使用 Vite + TypeScript 构建，纯 Canvas 渲染，无第三方游戏框架。

## 在线 Demo

GitHub Pages：<https://cameliorn.github.io/web-war-simulator/>

## Demo 功能

- **前 / 中 / 后三梯队**：前排 = 最前面三排（唯一开火的梯队，每排长度 = 战场宽度，即每翼前排 ≤ 3 × 战场宽度）；中排紧贴前排、**瞬间补位**（与前排同宽，各自 ≤ 3 × 战场宽度）；后排为纵深预备队、**慢速支援**（超出前排/中排宽度上限的兵力自动转入后排）。
- **按翼部署的火炮**：火炮可分别部署在左翼 / 中军 / 右翼后方（每个翼独立配置数量）；翼存活时火炮受保护，翼被歼后火炮暴露，敌方对应翼的士兵可以攻击火炮；火炮之间可以互相攻击（反炮）。
- **火炮面杀伤**：火炮对敌翼造成面积伤害，伤害正比于敌翼（前+中）阵型厚度，按前/中/后比例分摊；阵型越厚受创越重。
- **后排掩体**：火炮面杀伤对后排伤害显著降低（后排处于掩体内），主要威胁集中在前排与中排。
- **命中点逐点结算**：前排离散为独立士兵点，每一个点单独选择攻击对象并逐点结算（单发命中按概率击毙，概率 = 单位火力 × 步长 × 伤害水平倍率）；火炮也逐门结算，反炮火炮摧毁敌炮、压制火炮命中其目标前排点；敌翼前排打光后，攻击线自动延伸到中排、后排。
- **士气与组织度**：每个翼独立计算组织度，随伤亡下降——默认士气下伤亡 30% 组织度归零；初始士气可在战前调整（0.5~2）。士气在战斗中动态波动：本回合伤亡压制士气、击杀提振士气、双方总兵力比产生持续压力，并叠加少量随机扰动；士气越高组织度越坚韧（归零阈值按当前士气比例放大）。
- **溃退与逃生**：组织度归零的翼进入 10 回合溃退状态——期间无法攻击、只能被敌方击杀，且成为“大屠杀”阶段：每回合按剩余兵力 6% 溃散减员（击杀记在当面敌军头上），敌方对其火力加倍；翼标签显示“溃退中 n/10”，阵型变灰、指向它的攻击线变为实线高亮、红叉密集出现；倒计时结束视为逃生成功（“逃逸”），途中被全歼则记为“溃败”。
- **主动撤退决策**：将领面板可为每个翼选择“主动撤退”——立即开始 8 回合的有序撤退（比溃退更快离场），期间同样无法攻击，但减员率仅 0.8%/回合、敌方对其火力减半，被击杀率显著低于无序溃退；成功离场记为“有序撤退”。
- **三翼独立战斗 + 侧击**：左翼 / 中军 / 右翼各与敌方对应翼交战；某翼敌军被歼灭后，该翼自动转入侧击，把自身有效火力同时加入其余两翼的交战，等效于增加这些交战方向的战场宽度（不向友翼补充人数）。
- **线列阵型**：每翼由若干横排组成，**战场宽度**决定每排人数，**仅前三排有效射击**（每翼 `B_eff = min(本翼前排, 3 × 战场宽度)`）。
- **战斗随机性**：可调 0~1，为每翼直瞄火力和每方火炮生成乘性扰动；设为 0 时完全确定。
- **将领机制（决策树）**：战斗开始后，右侧将领面板实时生效——每个翼可指定打击目标（或自动）与人员调度方向（抽调后排支援友翼），每支火炮可指定压制目标与反炮策略，另可调整后排投入速度（慢/中/快）；左侧战前配置在战斗期间锁定。
- 可调参数：红蓝双方初始兵力、前/中/后梯队占比、每翼部署占比（左/中/右三个滑条）、后排支援速度、战场宽度、每翼火炮数量、作战效率 α/β、战斗随机性、伤害水平（0.005~1 倍，默认 0.025，默认一场约 1000 回合）、红蓝士气（0.5~2，默认 1）、模拟速度（0.1~20 次/秒，按整回合结算）。
- 主页只保留战斗界面：战场态势图红上蓝下、中间战线，两军中间拉开；每方呈 U 字阵型——中军平直正对、两翼内端接中军、外端向前斜伸；每方三翼各由前（实心高亮）/ 中（实心变暗）/ 后（空心）三梯队组成；翼标签显示每翼前/中/后/火炮数量、组织度与当前士气；火炮小方块部署在对应翼正后方；战斗时前三排的每一个士兵点和每一门火炮图标都单独绘制箭头指向自己的攻击对象——士兵可攻击敌方前三排任意一点（侧击为琥珀色），火炮指向敌方前排点或敌方火炮；指向敌方火炮的击杀线为实线，其余射击线为虚线；被击毙的士兵点会显示红色叉号标记约 3 秒。
- **独立统计页（stats.html）**：战斗页与统计页可同时打开，战斗数据每秒自动同步；统计页展示兵力曲线、按翼/兵种的击杀与战损表（初始/剩余/战损/士兵击杀/火炮击杀/剩余火炮/状态）、以及六个翼各自的兵力变化小图。
- 参数面板与将领决策栏均为可收起侧边栏（可分别收起/展开，也可同时收起），收起时战场画布自动撑满剩余宽度。
- 统计页兵力变化曲线：红蓝双方前/中/后共六条曲线，前排实线、中排虚线、后排点线。
- 模拟核心使用四阶龙格-库塔（RK4）积分，数值稳定。
- 一方兵力低于自身初始值 1% 时判定为溃败，战斗结束（避免线性律无限拖尾）。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 <http://localhost:5173>）。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm start` | 启动开发服务器并自动打开浏览器 |
| `npm run dev` | 启动开发服务器（热更新） |
| `npm run build` | 类型检查并构建生产版本到 `dist/` |
| `npm run preview` | 本地预览构建产物 |

> 构建产物使用相对路径，`npm run build` 后直接双击 `dist/index.html` 也可以运行，无需服务器。

## 项目结构

```text
web-war-simulator/
├── index.html          # 页面骨架与控制面板
├── package.json
├── tsconfig.json
└── src/
    ├── main.ts         # 入口：UI 绑定、参数读取、主循环
    ├── simulation.ts   # 兰彻斯特方程模拟核心（RK4 积分）
    ├── render.ts       # Canvas 战场态势与兵力曲线绘制
    └── style.css       # 界面样式
```
